なぜノート

身近な物の「形には理由がある」と「日常のなぜ」を、約50秒の手描きノート風ショート動画で解き明かすYouTubeチャンネルです。

動画のつくり方

  • 答えは公式資料・論文などの一次資料で確かめ、出典を概要欄に載せています。
  • 図は仕組みを説明するためのイメージ図です。
  • 音声は VOICEVOX（VOICEVOX:青山龍星 / VOICEVOX:春日部つむぎ）、音楽・効果音・絵はすべてオリジナルです。

このサイトについて

このサイトは、なぜノートが自分のチャンネルへ動画をアップロードするための仕組み（YouTube Data API を使う自作のツール）の説明ページを兼ねています。プライバシーポリシー
