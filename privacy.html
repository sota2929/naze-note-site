プライバシーポリシー

制定日：2026年10月28日

対象となるアプリ

「なぜノート」（以下、本アプリ）は、YouTubeチャンネル「なぜノート」の運営者が、自分のチャンネルに動画をアップロードするためだけに使う自作のツールです。運営者以外の人は利用しません。

使うGoogleのデータ

本アプリは、YouTube Data API の youtube.upload の権限だけを使い、運営者自身のチャンネルへ動画・タイトル・説明文をアップロードします。それ以外のGoogleアカウントの情報（メール、連絡先、視聴履歴など）を読み取ることはありません。

個人情報の収集

本アプリは、利用者や視聴者の個人情報を収集・保存・販売・第三者へ提供しません。アクセス解析や広告のためのデータも集めません。

認証情報の保管

アップロードに使う認証情報（OAuthのトークン）は、運営者が管理する暗号化された保管場所（GitHub のリポジトリ シークレット）にのみ保存し、公開しません。運営者はいつでも Googleアカウントの「サードパーティ製のアプリとサービス」 から権限を取り消せます。

Googleのポリシー

本アプリによるGoogle APIから受け取った情報の利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。YouTubeの利用には YouTube利用規約 と Googleプライバシーポリシー が適用されます。
